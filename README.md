# postman_API_Assessment

This is postman API assessment project.In this we can validate the post,get,put and delete calls working as expected.
## Pre Requisites

1. npm
2. Node v10+


## Getting Started

1. Clone repo `git clone https://github.com/Kusams/newman_Postman.git`
2. launch the terminal and run the command : `cd petStore/`
3. next run `  ./TestRunner.sh `
