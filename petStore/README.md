# 86400_API_Assessment

This is 86400 API assessment project.In this we can validate the post,get,put and delete calls working as expected.
## Pre Requisites

1. npm
2. Node v10+


## Getting Started

1. Clone repo `git clone https://github.com/Kusams/newman_Postman.git`
2. Run `npm install`
3. Run `npm run test`
